Unsolved challenges are not included.

## ✅ VERIFICATION STANDARDS

| Status | Meaning |
|--------|---------|
| ✅ **VERIFIED** | Recovered through authenticated decryption (GCM tag, signature verification, or direct reproduction from original artifacts) |
| ⚠️ **UNVERIFIED** | Reported but not independently reproduced; missing GCM tag check or solver script |
| 🔶 **PARTIAL** | Challenge has multiple flags; only some recovered |
| 🏠 **LOCAL_ONLY** | Flag recovered only in local testing environment; remote flag not captured |

> **We never guess flags. We never submit unverified flags as verified.**

# Master Flag Index

This index catalogs all flags recovered from the Lesotho CTF challenges, their verification status, and writeup locations.

## Verification Status Legend

- **VERIFIED** — Flag recovered through authenticated decryption (GCM tag check, signature verification, or direct reproduction from original artifacts)
- **UNVERIFIED** — Flag reported but not independently reproduced; missing GCM tag check or solver script
- **PARTIAL** — Challenge has multiple flags; only some recovered
- **LOCAL_ONLY** — Flag recovered only in local testing environment; remote flag not captured
